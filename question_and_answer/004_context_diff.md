# 各画面のtsxにおいてstateで管理・Contextで管理の違い

| 保存場所               |         画面切り替え | ページ再読み込み | タブを閉じる | ブラウザ再起動 |
| ---------------------- | -------------------: | ---------------: | -----------: | -------------: |
| 画面内の `useState`    |   失われる場合がある |         失われる |     失われる |       失われる |
| Context内の `useState` | Providerが残れば保持 |         失われる |     失われる |       失われる |
| `sessionStorage`       |                 保持 |             保持 | 通常失われる |   通常失われる |
| `localStorage`         |                 保持 |             保持 |         保持 |           保持 |
| サーバー・DB           |                 保持 |             保持 |         保持 |           保持 |

## より端的には

画面固有のuseState<br>
→ 画面が破棄されると失われる

Appより上のContext<br>
→ 画面が破棄されてもProviderが残るため保持される

ブラウザを閉じる<br>
→ Reactアプリ自体が終了するため、どちらも失われる
