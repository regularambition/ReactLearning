# useState・useRefの違い

| 項目               | `useState`               | `useRef`                     |
| ------------------ | ------------------------ | ---------------------------- |
| 値の参照           | 状態変数を直接参照       | `.current` で参照            |
| 値の変更           | setterを使用             | `.current`へ代入             |
| 変更時の再レンダー | 発生する                 | 発生しない                   |
| 主な用途           | 画面表示に影響する状態   | DOM参照、タイマーIDなど      |
| 今回の用途         | ダイアログを開くかどうか | 実際の `<dialog>` 要素の操作 |
